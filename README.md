# AI Doctor Simulator

> **Learn How Artificial Intelligence Recognizes Patterns From Data**  
> *An interactive educational web application designed for an 8th-standard National Science Fair exhibition.*

---

## ⚠️ STRICT EDUCATIONAL DISCLAIMER

> **Educational Simulation Only:**  
> This application does **NOT** diagnose diseases or provide medical care. Predictions are generated by comparing input features against a **fictional dataset of 150 training vectors** using pattern recognition formulas (K-Nearest Neighbors).  
> **Always consult qualified healthcare professionals for medical advice.**

---

## 🌟 Features & Highlights

1. **National Science Fair UI/UX**:
   - Glassmorphism aesthetic, soft glow shadows, dark/light themes, Inter & Outfit typography.
   - Interactive 2D Neural Node canvas with pulsing synapses and traveling data packets.

2. **16 Interactive Symptom Feature Cards**:
   - Card selection with feature weight metadata (e.g. *Fever: 90%*, *Vomiting: 95%*).
   - Quick Science Fair Presets (e.g. *School Kid Flu*, *Winter Sniffles*, *Gastro Upset*, *Healthy Control*).
   - Random Case Generator for impromptu demonstrations.

3. **5-Stage Animated AI Processing Engine**:
   - Multi-phase scanning sequence (Symptom Vectorization → 150 Dataset Query → KNN Distance Math → Confidence Calibration → Output Synthesis) with procedural audio synthesis (Web Audio API).

4. **Transparent Pattern Rationale & Analytics**:
   - Natural language breakdown of *why* the model predicted a category and why absence of certain symptoms reduced confidence.
   - Radial animated confidence gauge with color states (*Emerald High / Amber Moderate / Rose Low*).
   - Multi-dimensional Radar Chart & Category probability distribution via Recharts.
   - Top-3 Nearest Fictional Training Vectors comparison.

5. **Live "What-If" Sensitivity Explorer**:
   - Toggle individual symptoms in real-time to watch the model recalibrate its category and confidence.

6. **Exhibition Learning Modules**:
   - **How AI Learns**: 5-step visual pipeline from raw vector to confidence scores.
   - **AI vs Human Doctor Matrix**: In-depth comparison highlighting physical exams, lab tests, and medical ethics.
   - **4 Mistakes AI Makes**: Failure modes (Missing data, Dataset bias, Lack of context, Overfitting).
   - **150 Dataset Explorer**: Searchable and filterable table of all training samples.
   - **Science Fair Quiz**: 5-question interactive challenge with score counter, explanation modals, and celebratory confetti.
   - **Dr. Byte Floating Mentor**: Offline educational chatbot explaining ML concepts in 8th-grade friendly language.
   - **PDF Report Card Export**: Download styled science fair summary reports.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ & npm

### Installation
```bash
# Clone or navigate to the directory
cd "AI Doctor Simulator"

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
